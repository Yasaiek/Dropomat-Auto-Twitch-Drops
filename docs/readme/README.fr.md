## Ce qu’il fait

- **Choisir et mettre en file** – Les campagnes de drops ouvertes dans une seule liste. Cliquez sur les jeux dans l’ordre voulu – c’est votre file.
- **Regarde tout seul** – Ouvre une fenêtre muette et réduite, choisit un stream où les drops du jeu tournent vraiment et passe au suivant quand il se termine.
- **Suit les nouveaux drops** – Marquez un jeu d’une étoile : dès qu’une nouvelle campagne apparaît, il entre dans la file et démarre seul.
- **Affiche la vraie progression** – Lit la progression sur votre compte Twitch, montre chaque drop avec son icône et change de stream si rien n’avance.
- **Récupération en option** – Peut récupérer les drops gagnés pour vous – uniquement si Twitch confirme que le compte du jeu est lié.
- **12 langues** – Toute l’interface en 12 langues, modifiable à tout moment.

## Installation en une minute

1. Téléchargez le ZIP et décompressez-le dans un dossier que vous garderez.
2. Ouvrez chrome://extensions et activez le Mode développeur (en haut à droite).
3. Cliquez sur « Charger l’extension non empaquetée » et choisissez le dossier décompressé.
4. Connectez-vous sur twitch.tv, ouvrez Dropomat, cliquez sur les jeux voulus et appuyez sur Démarrer.

<p align="center"><img src="../img/install.png" alt="" width="820"></p>

> Fonctionne dans Chrome, Edge, Opera, Brave et les autres navigateurs Chromium.

### Mise à jour

Remplacez les fichiers du dossier et appuyez sur ⟳ à côté de Dropomat dans chrome://extensions. La file et les réglages sont conservés.

## Bon à savoir

**Le stream doit-il rester à l’écran ?**  
Non. Il tourne dans sa propre fenêtre muette, qui peut rester réduite pendant que vous jouez.

**Récupère-t-il les drops pour moi ?**  
Seulement si vous l’activez dans les Réglages. Sinon le jeu passe en « À récupérer » et la file continue.

**Est-ce sûr pour mon compte ?**  
Le visionnage automatisé est contraire aux conditions d’utilisation de Twitch : vous l’utilisez à vos risques. Votre connexion ne quitte jamais votre navigateur.

**Pourquoi une campagne manque-t-elle ?**  
Appuyez sur ⟳ dans l’onglet Campagnes. Si elle manque toujours, ajoutez le jeu par son nom dans l’onglet En cours ou suivez-le.

**Envoie-t-elle des données ?**  
Une fois par jour, l’extension ajoute +1 à un compteur public anonyme pour que cette page puisse afficher le nombre d’installations actives. Rien sur vous, votre compte ou ce que vous regardez n’est envoyé, et vous pouvez le désactiver dans les paramètres.
