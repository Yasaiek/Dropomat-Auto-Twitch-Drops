## できること

- **選んでキューに入れる** – 開催中のドロップキャンペーンを一覧表示。見たい順にゲームをクリックすれば、それがキューになります。
- **自動で視聴** – ミュートした最小化ウィンドウを開き、そのゲームのドロップが実際に有効な配信を選び、終了したら次へ進みます。
- **新しいドロップを追跡** – ゲームに星を付けておくと、新しいキャンペーンが始まったときに自動でキューに入り、視聴が始まります。
- **実際の進捗を表示** – Twitch アカウントから進捗を読み取り、各ドロップをアイコン付きで表示。進捗が止まると配信を切り替えます。
- **自動受け取り（任意）** – 獲得したドロップを代わりに受け取れます。Twitch がゲームアカウントの連携を確認できた場合のみ行います。
- **12 言語** – インターフェース全体が 12 言語に対応し、いつでも切り替えられます。

## 1 分でインストール

1. ZIP をダウンロードし、残しておくフォルダーに展開します。
2. chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダーを選びます。
4. twitch.tv にログインし、Dropomat を開いて見たいゲームをクリックし、「開始」を押します。

<p align="center"><img src="../img/install.png" alt="" width="820"></p>

> Chrome、Edge、Opera、Brave などの Chromium 系ブラウザーで動作します。

### 更新

フォルダー内のファイルを置き換え、chrome://extensions で Dropomat の横の ⟳ を押します。キューと設定は残ります。

## 知っておきたいこと

**配信を画面に出しておく必要はありますか？**  
いいえ。専用のミュートされたウィンドウで再生され、遊んでいる間は最小化したままで構いません。

**ドロップを代わりに受け取ってくれますか？**  
設定で有効にした場合のみです。無効のときはゲームが「受け取り待ち」になり、キューは先へ進みます。

**アカウントに影響はありませんか？**  
自動視聴は Twitch の利用規約に反するため、自己責任でご利用ください。ログイン情報がブラウザーの外に出ることはありません。

**一覧にキャンペーンが見当たらないのはなぜですか？**  
「キャンペーン」タブの ⟳ を押してください。それでも出ない場合は、「視聴」タブでゲーム名から追加するか、追跡してください。
