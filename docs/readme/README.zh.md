## 它能做什么

- **选择并排队** – 进行中的掉宝活动集中在一个列表里。按想要的顺序点击游戏，这就是你的队列。
- **自动观看** – 打开一个静音、最小化的窗口，挑选该游戏掉宝确实生效的直播，直播结束后自动换下一个。
- **关注新掉宝** – 给游戏加星标：出现新活动时，它会自动进入队列并开始观看。
- **显示真实进度** – 从你的 Twitch 账号读取进度，用图标显示每个掉宝，进度停滞时自动换直播。
- **可选的自动领取** – 可以替你领取已获得的掉宝——仅在 Twitch 确认游戏账号已绑定时进行。
- **12 种语言** – 整个界面支持 12 种语言，可随时切换。

## 一分钟安装

1. 下载 ZIP 并解压到一个会长期保留的文件夹。
2. 打开 chrome://extensions，开启“开发者模式”（右上角）。
3. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
4. 登录 twitch.tv，打开 Dropomat，点击想看的游戏，然后按“开始”。

<p align="center"><img src="../img/install.png" alt="" width="820"></p>

> 适用于 Chrome、Edge、Opera、Brave 等 Chromium 浏览器。

### 更新

替换文件夹中的文件，然后在 chrome://extensions 里点击 Dropomat 旁的 ⟳。队列和设置会保留。

## 须知

**直播必须留在屏幕上吗？**  
不用。它在独立的静音窗口里播放，你玩游戏时可以保持最小化。

**它会替我领取掉宝吗？**  
只有在设置里开启后才会。否则游戏会标记为“待领取”，队列继续往下走。

**对账号安全吗？**  
自动观看违反 Twitch 的服务条款，使用风险自负。你的登录信息不会离开浏览器。

**为什么列表里缺少某个活动？**  
在“活动”标签页点击 ⟳。如果还是没有，可在“观看”标签页按名称添加游戏，或者关注它。
